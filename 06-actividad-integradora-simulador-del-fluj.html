Actividad integradora: Simulador del flujo de registro del proceso

Introducción al flujo de una acción en el computador

En este recorrido, exploraremos cómo una acción cotidiana en tu computador pasa por diferentes etapas, desde la solicitud inicial en el software hasta la respuesta final del hardware. Identificaremos el papel de cada componente involucrado en el proceso.

Resumen del flujo de acción en el computador

Desde la solicitud inicial en el software hasta la respuesta final del hardware, cada componente del computador cumple un papel fundamental para garantizar que las acciones del usuario se ejecuten de manera eficiente y segura.

Software: Solicitud de una acción

El usuario interactúa con una aplicación (por ejemplo, al hacer clic en un botón para guardar un archivo). La aplicación genera una solicitud para realizar una acción específica.

System Call: Petición al sistema operativo

La aplicación utiliza una llamada al sistema (system call) para pedirle al sistema operativo que realice la acción solicitada, como escribir datos en el disco.

Modo Usuario/Kernel: Cambio de privilegio

El sistema operativo cambia del modo usuario al modo kernel para ejecutar operaciones que requieren privilegios especiales, garantizando la seguridad y el control del sistema.

Driver: Traducción de la solicitud

El sistema operativo utiliza un controlador (driver) específico para traducir la solicitud en instrucciones que el hardware correspondiente pueda entender.

Hardware: Ejecución física

El hardware (por ejemplo, el disco duro) recibe las instrucciones y ejecuta físicamente la acción solicitada, como escribir los datos en el disco.

Interrupción: Notificación de finalización

Una vez que el hardware termina la acción, envía una señal de interrupción al sistema operativo para avisar que la tarea ha finalizado.

Respuesta: Procesamiento y devolución del resultado

El sistema operativo procesa la notificación del hardware y devuelve el resultado a la aplicación, informando que la acción se ha completado correctamente.
