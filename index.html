Sistema Operativo: Intermediario entre Software y Hardware en la UFPS

¿Te has preguntado cómo una simple acción en tu computador, como guardar un archivo, recorre un complejo camino hasta el hardware y regresa a tu aplicación? Este curso te lleva a descubrir, paso a paso, el papel fundamental del Sistema Operativo como intermediario entre el software y el hardware. Explorarás cómo las aplicaciones se comunican con el hardware de manera segura y eficiente, comprenderás el proceso de las llamadas al sistema, los modos de ejecución, las interrupciones y los drivers. Al finalizar, dominarás el ciclo completo de comunicación y estarás listo para aplicar este conocimiento en tus proyectos de Ingeniería de Sistemas.
